Hermes mac-server

Hermes mac-server は、作成者本人が自宅の Mac で個人的に使うアシスタントです。一般には提供していません。

Hermes mac-server is a personal assistant used only by its creator on a home Mac. It is not offered to the public.

プライバシーポリシー / Privacy Policy

  • Google アカウントのデータ(Gmail、カレンダー、Drive、Docs、Sheets、連絡先)は、作成者本人の依頼に応えるためだけに使います。
  • データは本人の端末で処理し、第三者に販売・提供しません。広告には使いません。
  • 許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。
  • Google user data (Gmail, Calendar, Drive, Docs, Sheets, Contacts) is used only to carry out the creator's own requests.
  • Data is processed on the creator's own device and is never sold or shared with third parties, nor used for advertising.
  • Access can be revoked at any time from the Google Account's "Third-party apps & services" page.

Google API から得た情報の利用は、限定的な使用の要件を含む Google API Services User Data Policy に従います。

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
